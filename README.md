## О моде

**[MR] Mouse Navigation** - клиентский мод для **Minecraft 26.1 (Fabric & NeoForge)**, добавляющий навигацию боковыми кнопками мыши в интерфейсах игры. С ним нижняя боковая кнопка мыши (Mouse 4) работает как «Назад», верхняя боковая кнопка (Mouse 5) — как «Вперёд», а средняя кнопка мыши (колёсико / СКМ) позволяет отправлять сообщения в чате, при этом настроенная мышь в игре не меняется!

## Что умеет мод?

1. **Кнопка «Назад» (Mouse Button 4 / XBUTTON1 / нижняя боковая)**:
   - **Окна и меню (Настройки, сундуки, инвентарь, пауза, выбор мира и др.)**: закрывает экран или возвращает в предыдущее меню (эквивалент клавиши `Esc`).
   - **Книги и кафедры**: перелистывает на предыдущую страницу (`<`).
   - **Книга рецептов**: переключает на предыдущую страницу рецептов.
   - **Творческий инвентарь**: переключает на предыдущую вкладку групп предметов.
   - **Экран достижений**: переключение между вкладками достижений (нужен мод [**Better Advancements**](https://www.curseforge.com/minecraft/mc-mods/better-advancements)).
   - **Чат**: пролистывает историю отправленных сообщений назад (эквивалент стрелки `↑`).

2. **Кнопка «Вперёд» (Mouse Button 5 / XBUTTON2 / верхняя боковая)**:
   - **Книги и кафедры**: перелистывает на следующую страницу (`>`).
   - **Книга рецептов**: переключает на следующую страницу рецептов.
   - **Творческий инвентарь**: переключает на следующую вкладку групп предметов.
   - **Экран достижений**: переключение между вкладками достижений (нужен мод [**Better Advancements**](https://www.curseforge.com/minecraft/mc-mods/better-advancements)).
   - **Чат**: пролистывает историю отправленных сообщений вперёд (эквивалент стрелки `↓`).
   - **История экранов**: позволяет вернуться вперёд во вложенный экран, если вы вышли из него кнопкой назад.

3. **Средняя кнопка мыши (Mouse Button 3 / СКМ / Колёсико мыши)**:
   - **Чат**: мгновенная отправка набранного сообщения в чат (эквивалент клавиши `Enter`).

4. **Интеграция с ModMenu и гибкая настройка**:
   - В меню модов (**ModMenu**) доступно удобное конфигурационное окно, где можно по отдельности включить или отключить навигацию для каждого типа интерфейсов, включить звуковой отклик или инвертировать кнопки.

## Настройки (ModMenu)

При установленном **ModMenu** в настройках мода доступны следующие опции:
- **Общий переключатель**: включение/отключение работы мода.
- **Закрытие меню и экранов**: возврат назад / закрытие контейнеров.
- **История экранов**: возврат вперёд по истории открытых экранов.
- **Книги и кафедры**: навигация по страницам книг.
- **Книга рецептов**: переключение страниц рецептов.
- **Вкладки креатива**: переключение категорий предметов.
- **Достижения**: переключение между вкладками достижений (нужен мод [**Better Advancements**](https://www.curseforge.com/minecraft/mc-mods/better-advancements)).
- **История чата**: навигация по ранее отправленным сообщениям.
- **Отправка в чат по СКМ**: отправка сообщения нажатием на колёсико мыши.
- **Звуковой отклик**: воспроизведение тихого клика при навигации.
- **Инвертировать кнопки**: поменять местами Mouse 4 и Mouse 5.

Конфигурация сохраняется в файл `.minecraft/config/mrmousenavigation.json`.

## Совместимость с другими модами

- [**Mouse Tweaks**](https://www.curseforge.com/minecraft/mc-mods/mouse-tweaks): полная совместимость. Моды не конфликтуют и отлично дополняют друг друга — **Mouse Tweaks** отвечает за работу со слотами предметов (ЛКМ, ПКМ, скролл колёсиком), а **[MR] Mouse Navigation** отвечает за навигацию боковыми кнопками мыши (Mouse 4 и Mouse 5) и закрытие окон.
- [**Better Advancements**](https://www.curseforge.com/minecraft/mc-mods/better-advancements): полная поддержка переключения между вкладками достижений боковыми кнопками мыши.

## Установка

1. Скачайте `MrMouseNavigation-Fabric-26.1-byMr712-v1.0.jar` (для Fabric) или `MrMouseNavigation-NeoForge-26.1-byMr712-v1.0.jar` (для NeoForge) со страницы на [CurseForge](https://www.curseforge.com/minecraft/mc-mods/mr-mouse-navigation) или [GitHub Releases](https://github.com/byMr712/MrMouseNavigation-MinecraftMod/releases).
2. Убедитесь, что у вас установлен **Fabric Loader** или **NeoForge** (мод не требует сторонних API).
3. Поместите скачанный `.jar` файл в папку `.minecraft/mods`.
4. Запустите игру.

## Сборка из исходников

1. Клонируйте репозиторий и переключитесь на нужную ветку:
   ```bash
   git clone https://github.com/byMr712/MrMouseNavigation-MinecraftMod.git
   cd MrMouseNavigation-MinecraftMod
   git checkout 26.1
   ```
2. Выполните сборку:
   ```bash
   ./gradlew build
   ```
3. Собранные файлы будут находиться в `build/libs/`:
   - `MrMouseNavigation-Fabric-26.1-byMr712-v1.0.jar` (Fabric)
   - `MrMouseNavigation-NeoForge-26.1-byMr712-v1.0.jar` (NeoForge)
